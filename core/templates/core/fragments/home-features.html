Consent-first tracking

Klaro! gates every tracker. GA4, GTM, Meta Pixel, LinkedIn, UET, Clarity, Hotjar, TikTok, Pinterest, X and self-hosted Matomo load only after consent, and only when their ID is set in the admin.

SEO suite

Sitemap, robots.txt, canonical URLs, OpenGraph, JSON-LD organization and breadcrumb schema, llms.txt for AI crawlers, security.txt, humans.txt and an IndexNow command with its key proof route.

Middleware that works

Dynamic CSP built from the trackers you enable, scraper blocking on legal pages, X-Robots-Tag control, protected pages behind login and the outbound link snatcher. Each one has its own switch.

Lazy sections

Sections declare data-lazy-section and a fragment URL. The loader fetches on approach, re-executes fragment scripts and fires lazy-section-loaded for Lottie and reveal to pick up.

Lottie motion

Declarative data-lottie mounts: aspect-ratio boxes for zero layout shift, pausing offscreen, static frame fallback for reduced motion. The demo animation is authored by a Python build script.

Forms that fight back

Honeypot, signed time-trap, Turnstile, per-session rate limiting and PRG flow with one-shot conversion events. Bots see a success page and nothing else.
