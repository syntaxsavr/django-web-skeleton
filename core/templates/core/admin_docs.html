The ops-file system (autonomous AI changes)

A coding agent can request database and content changes without anyone at the keyboard: it writes a signed JSON file into ops/pending/, the daily maintenance pass (or manage.py ops_apply) validates and applies it. Rules: ai_-prefixed tables only, allow-listed content settings only, 24-hour validity, every file logged below. Security switches (login methods, consent, CSP, 2FA, registration) are never agent-editable. The full protocol is in AGENTS.md; signing helper: python tools/ops_sign.py <file>.
