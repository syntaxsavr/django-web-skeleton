The tour

Seven mechanisms, one page.

Every block below demonstrates one system. Open the page source: the markup is the documentation.

01

Hero entrance

A section marked data-hero-entrance sequences its data-hero-item children on load. The index page hero uses it with the giant letter.

First: the heading arrives.

Second: the supporting copy.

Third: the actions.

02

Lottie mounts

One declarative attribute per animation. The ratio box reserves space before the JSON loads, offscreen animations pause, and reduced motion parks on a static frame.

The animation is generated by tools/lottie/build_demo.py: shape layers only, no external assets.

03

Scroll reveal

Elements below the fold rise in as they enter the viewport, staggered by 45ms. Any element with data-reveal joins the system. It switches itself off for reduced motion and print.
