# django-skeleton-eu-ready

A Django website starter for the things I was tired of building again and
again. EU web compliance was draining my energy, so here you go.

It includes a consent manager, opt-in analytics loaders, legal-page starters,
contact-form defences, CSP, SEO and AI crawler files, authentication, protected
pages, accessibility preferences, Lottie support, lazy sections, compressed
static files, and an admin control panel for switching features on or off. It
uses plain CSS and JavaScript with no frontend build step and is set up for AI
coding agents.

Clone it, open it with your coding agent, and type:

> init the template

The agent will ask a short set of questions about your site, design, motion,
privacy needs, features, and deployment. It will then configure `.env`, tailor
the project, run the checks, and remove the one-time setup file.

This is **probably EU-ready**, but that is not a legal guarantee. Laws, guidance,
and your data processing can change what is required. You are responsible for
reviewing the result, supplying correct legal text, collecting valid consent,
and deciding whether the project is suitable for your use.

Built on [Django](https://www.djangoproject.com/) with
[Klaro](https://klaro.org/), [Lottie](https://airbnb.io/lottie/),
[WhiteNoise](https://whitenoise.readthedocs.io/),
[Cloudflare Turnstile](https://developers.cloudflare.com/turnstile/), and
[IndexNow](https://www.indexnow.org/). See [AGENTS.md](AGENTS.md) for the
architecture and working rules.
